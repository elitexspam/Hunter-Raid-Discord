# Hunter Bot

Bot para Discord voltado para automação em servidores-alvo, com foco em operação contínua e execução simples via terminal.

## Visão geral

Este projeto disponibiliza um executável já configurado com o token embutido, permitindo que o bot fique online rapidamente sem a necessidade de configurar variáveis de ambiente manualmente.

## Funcionalidades

- Execução direta via arquivo `.exe`
- Token já integrado no executável
- Mantém o bot online para uso contínuo
- Comandos executados pelo terminal
- Configuração simples para uso em servidor alvo

## Requisitos

Antes de usar, certifique-se de que:

- Você tem permissão administrativa no servidor alvo
- O servidor onde o bot será adicionado é de sua propriedade ou você possui autorização para operar nele
- O executável foi baixado de uma fonte confiável

## Como utilizar

1. Adicione o bot ao servidor alvo (requer administração):
   https://discord.com/oauth2/authorize?client_id=1553592235646517268

2. Baixe o executável mais recente do projeto

3. Execute o arquivo `.exe`

4. O bot ficará online e você poderá controlar/monitorar os comandos pelo terminal

## Observações importantes

- O executável já vem com o token embutido
- O projeto foi pensado para uso prático e rápido
- Use apenas em ambientes e servidores em que você tenha autorização legal para operar

## Aviso de uso

Este tipo de ferramenta pode interagir com plataformas externas e exigir permissões elevadas. Use com responsabilidade, em conformidade com as regras do servidor e com os termos de uso da plataforma.
